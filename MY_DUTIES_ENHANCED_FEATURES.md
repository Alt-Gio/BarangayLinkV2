## 💡 Usage Examples

### View Overdue Tasks
1. Click **"Show Overdue Only"** button
2. See count badge with number of overdue tasks
3. Tasks are automatically sorted by due date

### Quick Task Update
1. Find your task in Event Duties
2. Click **"Start"** to begin working
3. See success message confirmation
4. Click **"Complete"** when finished
5. Task moves to "Done" status instantly

### Find Specific Tasks
1. Type keywords in search box
2. Use priority/status dropdowns
3. Apply sort order (due date recommended)
4. Click "Clear Filters" to reset

### Navigate to Full Boards
- **Event Tasks**: Click "Event Board" button → Event Control Board
- **Project Tasks**: Click "View in Projects" → Projects page

## 🆘 Troubleshooting

### Success Message Doesn't Appear
- **Cause**: May be dismissed too quickly
- **Solution**: Messages auto-dismiss after 3 seconds

### Can't Update Task Status
- **Cause**: Already updating another task
- **Solution**: Wait for current update to complete

### Filter Not Working
- **Cause**: Conflicting filters active
- **Solution**: Click "Clear Filters" and reapply

### No Tasks Showing
- **Cause**: Filters too restrictive
- **Solution**: Check if "Show Overdue Only" is active
