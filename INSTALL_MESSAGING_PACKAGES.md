# 📦 Install Required Packages for Messaging Features

Run this command in your project directory:

```bash
npm install emoji-mart@latest react-dropzone@latest yet-another-react-lightbox@latest react-image-gallery@latest
```

## Package Details:

### 1. emoji-mart (Emoji Picker)
- **Purpose:** Beautiful emoji picker for message reactions
- **Size:** ~200KB
- **Features:** Search, categories, recent emojis, skin tones

### 2. react-dropzone (Drag & Drop)
- **Purpose:** Easy drag-and-drop file upload
- **Size:** ~30KB
- **Features:** Multi-file, validation, styling hooks

### 3. yet-another-react-lightbox (Image Viewer)
- **Purpose:** Lightbox for viewing images
- **Size:** ~50KB
- **Features:** Zoom, slideshow, keyboard navigation

### 4. react-image-gallery (Album Viewer)
- **Purpose:** Image gallery/carousel
- **Size:** ~40KB
- **Features:** Thumbnails, fullscreen, touch support
