# 🚀 Quick Reference Guide - Event Progress & Duties

## ⚡ Quick Start

### **See Event Progress:**
1. Go to **Events** page
2. Look at any event card
3. Progress bar shows at bottom: `▓▓▓▓▓░░░░░ 50%`

### **See Your Event Tasks:**
1. Go to **Tasks → My Tasks**
2. Scroll down to **"Event Duties"** section
3. See all events you're assigned to
4. Click **"Go to Event Board"** to work

### **Create Tasks (with time validation):**
1. Open **Event Control Board**
2. Click **"+ Create Task"**
3. If event has ended → ❌ Error appears
4. If event is active → ✅ Task created

### **Progress Colors:**
- **Emerald Green** (`▓`) - Completed portion
- **Gray** (`░`) - Remaining portion

### **Task Priority Colors:**
- 🔴 **Red** - Critical
- 🟠 **Orange** - High  
- 🟡 **Yellow** - Medium
- 🔵 **Blue** - Low

### **Task Status Colors:**
- ✅ **Green** - Done
- 🔵 **Blue** - In Progress
- 🔴 **Red** - Blocked
- ⚪ **Gray** - To Do

### **Special Badges:**
- 🟠 **"Soon"** - Event starting within 7 days
- 🔴 **Red Border** - Task is overdue
- ⏰ **Clock** - Estimated hours shown

## ⏰ Time Validation Rules

### **Can Create Tasks:**
✅ Event hasn't started yet
✅ Event is currently happening
✅ Event ends in the future

### **Cannot Create Tasks:**
❌ Event has already ended
❌ Event date is in the past

### **Error Message:**
```
❌ Cannot add tasks to past events. 
   This event has already ended.
```

## 🆘 Troubleshooting

### **Progress Bar Not Showing:**
- **Reason:** No tasks created yet for the event
- **Solution:** Create tasks in Event Control Board

### **Can't Create Task:**
- **Reason:** Event has ended
- **Error:** "Cannot add tasks to past events"
- **Solution:** Event is in the past, no tasks can be added

### **Don't See Event Duties:**
- **Reason:** No tasks assigned to you
- **Solution:** Ask event organizer to assign tasks

### **Progress Shows 0%:**
- **Reason:** No tasks marked as "Done" yet
- **Solution:** Complete tasks and mark status as "Done"

## 📊 Data Explained

### **Progress Calculation:**
```
Progress = (Completed Tasks ÷ Total Tasks) × 100

Example:
- 5 tasks done out of 10 total
- Progress = (5 ÷ 10) × 100 = 50%
```

### **Task Counts:**
- **Total Tasks** - All non-archived tasks
- **Completed Tasks** - Tasks with status "done"
- **Remaining** - Total minus Completed
