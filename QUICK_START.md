# 🚀 Quick Start Guide

## To Activate Enhanced Features

Run this command in your terminal:

```bash
npx convex dev
```

That's it! All enhanced features will be available.

---

## What You'll Get

### ✅ Already Working (No deployment needed):
- Professional ProjectWizard for creating projects
- Quick view tabs (All/Pending/Active/Completed)
- Pending approvals badge for managers
- Modern gradient UI

### ✅ After Running `npx convex dev`:
- Complete approval workflow

---

## Quick Test

1. **Start Convex:**
   ```bash
   npx convex dev
   ```

2. **Navigate to `/projects`**

3. **Click "Create Project"** (the gradient button)

4. **Complete the 6-step wizard:**
   - Step 1: Enter title, description, department
   - Step 2: Set dates and priority
   - Step 3: Add budget and impact
   - Step 4: Define success criteria
   - Step 5: Create milestones
   - Step 6: Set visibility

5. **Submit** - You'll be redirected to the project page!

---

## For Managers/Admins

After a BUILDER creates a project:

1. You'll see **"X Pending Approval"** badge in header
2. Click to filter pending projects
3. Navigate to project detail
4. Click **"Approve"** or **"Reject"**
5. Creator gets notified automatically!
